# Citation and archival release

`CITATION.cff` already provides dataset citation metadata. Cite the collection and applicable upstream works; its component licenses differ. The v1.0.0 release records this public collection and research guide. Later documentation changes should be cited by their own version or commit.

## DOI activation

A DOI has **not** been issued by this repository. The GitHub connection does not provide access to a Zenodo account. The account holder must sign in to Zenodo and enable this repository under its GitHub integration. After enabling it, create a new GitHub release: earlier releases are not automatically archived. Check Zenodo's resulting file inventory, version, authorship, component licensing and DOI, then add the actual DOI to CITATION.cff and README. Never use a placeholder DOI badge as if registered.

For this mixed collection, preserve `metadata/licenses.csv` and `THIRD_PARTY_NOTICES.md` in the archive. A top-level collection license does not replace component restrictions. Verify every archived subset is eligible for redistribution under its stated terms.

Official instructions: [GitHub citation files](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files), [GitHub archiving and DOI](https://docs.github.com/en/repositories/archiving-a-github-repository/referencing-and-citing-content), [Zenodo release archiving](https://help.zenodo.org/docs/github/archive-software/github-upload/).
