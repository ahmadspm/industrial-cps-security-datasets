# Citation and archival reuse

Use `CITATION.cff` to cite this collection and cite applicable upstream works separately. Record the repository version or commit identifier used in each experiment. Component terms differ; preserve `metadata/licenses.csv` and `THIRD_PARTY_NOTICES.md` with redistributed copies.

For a persistent archival copy, GitHub releases can be connected to an archival service such as Zenodo. An issued DOI identifies its specific archived record; use a DOI only when it resolves to the intended dataset version. The repository URL and version remain the citation route for these files.

Official instructions: [GitHub citation files](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files), [GitHub archiving and DOI](https://docs.github.com/en/repositories/archiving-a-github-repository/referencing-and-citing-content), [Zenodo release archiving](https://help.zenodo.org/docs/github/archive-software/github-upload/).
